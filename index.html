เฉลย Mini-Lab 1: HTML5 Semantic Structure & Responsive Layout
เปิดไฟล์ minilab1.html

โจทย์ให้ตั้งโครงสร้าง Semantic Web สำหรับ Dashboard และสร้าง KPI Cards ด้วย CSS Flexbox ที่รองรับ Mobile-first

1. โครงสร้าง HTML5 Semantic (index.html)

<!-- HTML5 Semantic Elements สำหรับ Data Dashboard -->
<header>
  <h1>E-Commerce Sales Performance Dashboard 2026</h1>
  <p>รายงานสรุปประสิทธิภาพยอดขายรายเดือน ปี 2026</p>
</header>

<main>
  <!-- ส่วนแสดงผล KPI Cards -->
  <section class="kpi-container">
    <article class="kpi-card">
      <h3>ยอดขายรวมทั้งหมด</h3>
      <p class="value">4,250,000 ฿</p>
    </article>
    <article class="kpi-card highlight">
      <h3>เดือนที่ยอดขายสูงสุด</h3>
      <p class="value">580,000 ฿ (Aug)</p>
    </article>
  </section>
</main>

2. ชุดคำสั่ง CSS Mobile-first Layout (styles.css)

/* Mobile-first Layout (ค่าเริ่มต้นสำหรับจอเล็ก < 768px) */
.kpi-container {
  display: flex;
  flex-direction: column; /* เรียงต่อกันแนวตั้งบนมือถือ */
  gap: 16px;
}

/* Responsive Breakpoint สำหรับ Tablet/Desktop (≥ 768px) */
@media (min-width: 768px) {
  .kpi-container {
    flex-direction: row; /* ขยายเป็นแนวนอนเรียงคอลัมน์บนจอใหญ่ */
  }
}
เฉลย Mini-Lab 2: SVG Bar Chart & Accessibility (ARIA)
เปิดไฟล์ minilab2.html

โจทย์ให้สร้าง SVG Bar Chart ยอดขาย 12 เดือน ปรับสเกลแท่งกราฟ ไฮไลต์จุด Peak ส.ค. และใส่ ARIA Accessibility

<!-- SVG Bar Chart พร้อม ARIA สำหรับ Screen Reader -->
<svg viewBox="0 0 680 230" role="img" aria-labelledby="svg-title svg-desc">
  <title id="svg-title">กราฟแท่งแสดงยอดขายรายเดือน ปี 2026</title>
  <desc id="svg-desc">ยอดขายรวม 4.25 ล้านบาท สูงสุดสิงหาคม 580,000 บาท</desc>

  <!-- แกน Baseline X -->
  <line x1="40" y1="180" x2="660" y2="180" stroke="#cbd5e1" />

  <!-- แท่งยอดขายปกติ (ม.ค. 250k) -->
  <rect x="50" y="122" width="36" height="58" fill="#2563eb" />

  <!-- แท่ง Peak ยอดขายสูงสุด (ส.ค. 580k Highlight สีส้ม #f59e0b) -->
  <rect x="400" y="45" width="36" height="135" fill="#f59e0b" />
  <text x="418" y="38" fill="#b45309" font-weight="bold">580k ★</text>
</svg>

สูตรการคำนวณตำแหน่ง SVG Rectangle:

• ความสูงแท่ง (height) = (ยอดขายเดือนนั้น / ยอดขายสูงสุด 600,000) * 140px
• พิกัดแนวตั้ง (y) = Baseline(180) - height

เฉลย Mini-Lab 3: Data Storytelling, QA & AI Logs
เปิดไฟล์ minilab3.html

1. รายการตรวจสอบ QA & Ethics Checklist

Lighthouse Audit Passed (≥ 80):

โครงสร้าง HTML5 Semantic และภาพ SVG ช่วยให้ได้คะแนน Performance 95+ และ Accessibility 100

Contrast Ratio & Color-blind Safe:

ใช้สีฟ้าเข้ม (#2563eb) และส้ม (#f59e0b) บนพื้นหลังขาว มีค่า Contrast Ratio ≥ 4.5:1 ตามมาตรฐาน WCAG AA

Data Ethics (Unbiased Axis):

เริ่มต้นแกน Y จาก 0 เสมอ ไม่ตัดทอนแกน (Truncated Axis) เพื่อป้องกันการตีความข้อมูลคลาดเคลื่อน
